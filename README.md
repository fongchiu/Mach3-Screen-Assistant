# Mach3 屏幕分析助手 – 软件介绍说明
一、软件定位
Mach3 屏幕分析助手 是一款专门用于解析、可视化、分析 Mach3 数控软件屏幕配置文件（CSV 导出数据）的辅助工具。它帮助您快速理解 Mach3 自定义屏幕的布局结构、控件类型、功能关联以及背后的 VB 脚本逻辑，从而为二次开发、界面模仿、故障排查、教学演示提供直观、高效的支撑。

本软件采用 PWA（渐进式 Web 应用） 技术构建，无需安装，打开浏览器即可使用，并支持安装到桌面如同原生应用。所有数据均保存在本地（IndexedDB），无任何隐私上传，可离线使用。

二、主要功能
1. CSV 文件导入与历史管理
支持拖拽或点击上传 CSV 文件（自动识别分隔符：分号/逗号，自动处理 GBK/UTF-8 编码）。

解析后自动提取 Page、PosX1、PosY1、Width、Height、Ctrl Type、Ctrl Fct、Txt on Ctrl（脚本）等字段。

所有导入的文件自动保存至浏览器本地数据库（IndexedDB），形成历史记录列表。

可单独删除某条历史，或一键清除全部历史，方便管理。

2. 页面布局可视化
根据 PosX1, PosY1, Width, Height 绝对定位，生成 1366×768 画布，模拟 Mach3 屏幕真实布局。

每个控件以彩色卡片形式呈现：

🔵 图像按钮（Image button）

🟢 数字读数（DRO）

🔴 指示灯（LED）

🟣 标签（Label）

⚫ 其他类型（图像、G代码区域等）

卡片上显示中英文对照的功能名称（例如“主轴正转 (Spindle CW)”），可自定义翻译字典。

3. 页面切换与过滤
左侧边栏列出所有解析到的页面编号（如 Page 1,2,3,4,50…），点击即切换画布内容。

过滤按钮（按钮 / DRO / LED / 标签）可快速筛选控件类型，帮助聚焦特定元素。

重置按钮恢复全部控件显示。

4. 控件详情查看
点击任意卡片，弹出模态窗显示完整信息：

控件类型（中英文）

功能名称（中英文）

原始 VB 脚本（Txt on Ctrl）

OEM 代码、显示格式、图片路径等

方便您对照 Mach3 文档，理解每个按钮的逻辑。

5. 鼠标放大镜（悬浮详情）
点击工具栏 “🔍 放大镜” 按钮激活。

鼠标悬停在任意控件上，跟随显示一个放大信息浮窗，无需点击即可快速预览控件详情。

再次点击按钮关闭放大镜。

6. 画布缩放与侧边栏调节
缩放按钮（+ / - / 重置）可对画布进行 30% ~ 200% 的等比缩放，适应不同屏幕尺寸。

侧边栏宽度可拖拽调节（150px ~ 500px），为主视图腾出更多空间。

7. 完全离线可用 & 可安装
基于 Service Worker 实现离线缓存，首次访问后即使断开网络也能使用。

浏览器中点击“安装”即可将应用添加到桌面/开始菜单，像本地软件一样运行。

八、FAQ
Q：生成的画布大小是固定的吗？
A：画布原始尺寸为 1366×768，这是 Mach3 屏幕的典型分辨率。您可以通过缩放按钮或浏览器缩放调整大小。

Q：支持哪些 CSV 格式？
A：支持逗号或分号分隔，自动识别编码（UTF-8/GBK）。需要包含列：Page, PosX1, PosY1, Width, Height, Ctrl Type, Ctrl Fct, Txt on Ctrl 等。

Q：历史记录会丢失吗？
A：不会。所有记录保存在浏览器的 IndexedDB 中，除非手动清除或浏览器清理缓存。不同浏览器/设备的数据独立。

Q：能否修改翻译词典？
A：可以。打开 index.html，在脚本开头的 funcTranslation 对象中添加或修改键值对即可。

Q：遇到 Bug 怎么办？
A：请提供浏览器控制台（F12）的错误截图，以及所用 CSV 文件的示例（脱敏后）。
